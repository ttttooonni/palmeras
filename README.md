# HotelTalk · Palmeras V1 definitiva

100 frases prácticas para compañeros del hotel.

Idiomas: español → inglés, alemán, francés, polaco e italiano.
Categorías: Atención, Restaurante, Buffet, Bebidas, Comida, Alergias, Hotel, Maspalomas y Transporte.

Incluye buscador, banderas, audio con SpeechSynthesis sin exigir una voz concreta, favoritos, progreso por idioma, instalación PWA, offline y diseño móvil de uso a una mano.

La identidad UGT Palmeras es cercana y discreta. Sin marca comercial del hotel.
